# Cooperative Multi-Agent Reinforcement Learning for Fair Dynamic Pricing
Repository containing all the source code used for the paper 'Cooperative Multi-Agent Reinforcement Learning for Fair Dynamic Pricing'. 

Work done by Vishwanath Vinod under the guidance of Professor Rachel Kalpana Kalaimani as part of an Undergraduate Research Project at IIT Madras.

## Paper
*Title:* Cooperative Multi-Agent Reinforcement Learning for Fair Dynamic Pricing \
*Authors:* Vishwanath Vinod & Rachel Kalpana Kalaimani \
*Conference:* The 14th Computing Conference 2026, 9-10 July 2026, London, United Kingdom.
